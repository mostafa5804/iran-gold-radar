# رادار طلای ایران — Iran Gold Radar

نسخه **0.3.0** · داشبورد روشن، فارسی و راست‌به‌چپ برای هر گرم طلای **۱۸ عیار / ۷۵۰ بازار ایران به تومان**.

[بازکردن سایت](https://mostafa5804.github.io/iran-gold-radar/)

## هر نفر با کلید خودش

قیمت‌های بازار بدون کلید قابل مشاهده‌اند. تحلیل هوشمند و پیش‌بینی تنها با کلید شخصی بازدیدکننده اجرا می‌شوند:

1. در سایت «واردکردن کلید API» را بزنید.
2. از لینک [Google AI Studio](https://aistudio.google.com/apikey) کلید خود را دریافت کنید.
3. کلید را وارد و «اتصال و اعمال تنظیمات» را بزنید؛ سایت مدل‌های قابل دسترس همان کلید را دریافت می‌کند. برای انتخاب مدل دیگر، از «بررسی کلید و دریافت مدل‌ها» و جست‌وجوی مدل استفاده کنید.
4. «تحلیل و ساخت مسیر آینده» را اجرا کنید. درخواست‌ها و هزینه/سهمیه متعلق به حساب Google خودتان هستند؛ وجود کلید به معنی رایگان‌بودن یا دسترسی به همه مدل‌ها نیست.

انتخاب اولیه، در صورت وجود در فهرست واقعی کلید، `gemini-3.8-flash` است. مدل‌های Pro فقط با انتخاب کاربر اجرا می‌شوند. فهرست شامل مدل‌های متنی دارای generateContent است؛ پشتیبانی Google Search و URL Context هنگام درخواست بررسی می‌شود. مدل ناموجود یا بدون سهمیه به مدل گران‌تر تبدیل نمی‌شود.

## کلید و حریم خصوصی

- **هیچ کلید مشترک سازنده، اتصال به GitHub Actions برای تحلیل، یا تحلیل Gemini سروری وجود ندارد.** کلید در کد سایت نیست.
- کلید با هدر `x-goog-api-key` مستقیماً از مرورگر به Google ارسال می‌شود؛ به سازنده یا GitHub ارسال نمی‌شود.
- دو گزینه وجود دارد: «تا پایان این نشست» در `sessionStorage` (پیش‌فرض) و «ذخیره در این مرورگر» در `localStorage` تا حذف دستی. تغییر روش، ذخیره قبلی را پاک می‌کند. «پاک‌کردن کلید» هر دو محل و حافظه را پاک و تحلیل در جریان را لغو می‌کند.
- کلید فقط در محل انتخابی کاربر ذخیره می‌شود و داخل پشتیبان، دفتر تحلیل‌ها یا گزارش نمی‌آید. گزارش، منابع دستی و دارایی محلی‌اند و برای بازدیدکنندگان دیگر منتشر نمی‌شوند.
- مرورگر محیط ذخیره‌سازی رمزنگاری‌شده برای کلید نیست؛ اسکریپت‌های همان origin یا افزونه‌های دارای مجوز ممکن است به آن دسترسی داشته باشند. GitHub Pages سایت‌های یک حساب origin مشترک دارد. روی دستگاه مشترک از نگهداری کلید استفاده نکنید.
- داده بازار، منابع فعال و متن پژوهش برای تولید/ساختاربندی تحلیل به Google می‌رود؛ مبلغ سرمایه و معاملات شخصی ارسال نمی‌شود. دو درخواست اصلی Gemini به‌علاوه دریافت فهرست مدل‌ها استفاده می‌شود.
- فونت محلی است و اسکریپت اجرایی شخص ثالث از CDN بارگذاری نمی‌شود. HTML پیشنهادهای جست‌وجوی Google داخل iframe sandbox بدون مجوز اجرای اسکریپت نمایش داده می‌شود. متن‌های مدل به‌صورت امن رندر می‌شوند.

## راه‌اندازی انتشار و حذف Secret قدیمی

در GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

اکشن فقط قیمت‌ها و تاریخچه TGJU را ساعتی دریافت، آزمون‌ها را اجرا و پوشه `public/` را منتشر می‌کند. به هیچ Secret مربوط به Gemini نیاز ندارد. مالک می‌تواند **`GEMINI_API_KEY`** را از **Settings → Secrets and variables → Actions** حذف کند؛ متغیر قدیمی `GEMINI_MODEL` نیز دیگر استفاده نمی‌شود. نسخه جدید مقدار هیچ‌کدام را نمی‌خواند. حذف این تنظیم از GitHub کلید را در Google باطل نمی‌کند.

فایل‌های گزارش و فهرست مدل سروری از نسخه جاری و انتشار حذف شده‌اند؛ گزارش‌های عمومی قبلی ممکن است در تاریخچه Git باقی بمانند. تنظیم خصوصی/عمومی مخزن توسط این نسخه تغییر نمی‌کند. سایت ورود کاربری یا همگام‌سازی بین دستگاه‌ها ندارد.

## تحلیل و نمودار

- نرخ واقعی طلای ۱۸ عیار، دلار آزاد و اونس از TGJU، با زمان منبع و دریافت. ریال فقط یک بار به تومان تبدیل می‌شود. اکشن تیک لحظه‌ای نیست و زمان‌بندی GitHub تضمین دقیقه‌ای ندارد.
- تاریخچه OHLC، RSI14، SMA20 و ATR14؛ تاریخچه ابتدای کار محدود است و در اجراهای بعدی انباشته می‌شود.
- اختلاف با ارزش محاسباتی `اونس × دلار × ۰٫۷۵ ÷ ۳۱٫۱۰۳۴۷۶۸`؛ این اختلاف به‌تنهایی حباب قابل تخلیه یا فرصت آربیتراژ نیست.
- پژوهش خودکار با Google Search درباره تورم ایران/آمریکا، سیاست بانک مرکزی، دلار، جنگ/تحریم/مذاکرات، اونس، نرخ بهره، تقاضای طلا و تکنیکال. هر منبع دستی مکمل پژوهش خودکار است.
- Gemini ابتدا گزارش مستند و فرض‌های سناریو را می‌نویسد. درخواست دوم همان فرض‌ها را به JSON تبدیل می‌کند. قرارداد در `public/research-contract.json` و اعتبارسنجی و محاسبات در `public/forecast.js` هستند. شماره ارجاع معتبر به معنی تأیید انسانی همه ادعاهای مدل نیست.
- سه سناریوی پایه، کاهش تنش و تشدید تنش برای ۷،۳۰،۹۰،۳۶۵ روز. اعداد، فرض‌های قضاوتی AI هستند؛ مدل آماری آموزش‌دیده یا دقت اثبات‌شده نیستند.
- قیمت آینده = قیمت مبنا × تغییر دلار × تغییر اونس × نسبت صرف داخلی. تورم و خبر از طریق این فرض‌ها وارد می‌شوند؛ ضریب جدا برای جنگ یا تورم دوباره اضافه نمی‌شود.
- در صورت ارائه بازه، نقطه میانی حسابیِ آن با توضیح صریح برای ترسیم خط به‌کار می‌رود؛ به معنی محتمل‌ترین مقدار نیست. بین افق‌ها فرض‌ها خطی درون‌یابی می‌شوند. دامنه سایه‌دار کمینه/بیشینه سه سناریو است، نه فاصله اطمینان یا احتمال آماری.
- محور زمان گذشته و آینده دو مقیاس متفاوت دارد. بازده واقعی = نسبت قیمت آینده به مبنا تقسیم بر `(۱ + تورم انتظاری سالانه)^(روز/۳۶۵)` منهای یک. تورم مشاهده‌شده، سالانه متوسط، نقطه‌ای و انتظاری از هم جدا هستند. تورم ناموجود به صفر تبدیل نمی‌شود.
- در نمای پس از تورم، آینده به قدرت خرید زمان تحلیل تبدیل می‌شود؛ تاریخچه همچنان اسمی است. پس از ۲۴ ساعت، تغییر بیش از ۵٪ هر عامل، یا داده بازار قدیمی، خط آینده متوقف می‌شود. این آستانه قاعده عملیاتی است، نه معیار کالیبره‌شده.
- درصد دقت، احتمال رشد و مزیت راهبرد پس از هزینه هنوز آزمون خارج از نمونه ندارند و نمایش داده نمی‌شوند. کد مدل مرجع قدیمی صرفاً برای آزمون‌های قبلی باقی مانده و عملکرد آن به پیش‌بینی AI نسبت داده نمی‌شود.

## منابع و دارایی شخصی

«افزودن منبع» از لینک HTTPS عمومی یا متن پشتیبانی می‌کند؛ حداکثر ۸ منبع، هرکدام ۴۰۰۰ نویسه و مجموع ۱۶ هزار نویسه. هرکدام را می‌توان فعال/غیرفعال یا حذف کرد. منابع فعال با کلید خود کاربر به Google می‌روند. تنها در صورت فراداده موفقیت URL Context، لینک «دریافت‌شده» اعلام می‌شود؛ این وضعیت صحت خبر را تضمین نمی‌کند. متن کاربر تا تأیید مستقل یک ادعاست.

بودجه، معاملات، کارمزد و وزن آب‌شده به معادل عیار ۷۵۰ محاسبه می‌شوند. نرخ بازخرید فروشنده برای ارزش‌گذاری در اولویت است. تقسیم نقدینگی به پله‌ها مجوز خرید نیست. پشتیبان JSON کلید API ندارد؛ با پاک‌کردن داده مرورگر، اطلاعات محلی حذف می‌شود.

## توسعه و آزمون

Python 3.10+ و Node 20+، بدون dependency اجرایی:

```bash
python3 scripts/collect.py
npm test
python3 -m unittest discover -s tests -p 'test_*.py'
npm run dev -- --host 0.0.0.0 --port 4173 --strictPort
```

TGJU آداپتور صفحات عمومی بدون SLA است؛ تغییر HTML یا محدودیت دسترسی می‌تواند دریافت را متوقف کند. داده خراب رد و نرخ قبلی با وضعیت stale حفظ می‌شود. تازه‌بودن دریافت همیشه معادل تازه‌بودن معامله نیست.
