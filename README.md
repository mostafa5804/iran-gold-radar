# رادار طلای ایران — Iran Gold Radar

نسخه **0.1.0** · داشبورد فارسی و راست‌به‌چپ برای **هر گرم طلای ۱۸ عیار / ۷۵۰ بازار ایران، به تومان**.

## راه‌اندازی GitHub Pages

1. در **Settings → Pages → Build and deployment → Source** گزینه **GitHub Actions** را انتخاب کنید.
2. در **Settings → Secrets and variables → Actions → New repository secret** کلید خود را با نام دقیق **`GEMINI_API_KEY`** ثبت کنید. مقدار Secret فقط کلید Google AI Studio است؛ آن را در فایل یا Issue ننویسید.
3. اختیاری: در تب **Variables** متغیر `GEMINI_MODEL` را با شناسه مدل دارای پشتیبانی Google Search قرار دهید؛ پیش‌فرض `gemini-2.5-flash` است. مدل ناموجود یا بدون دسترسی خودکار به مدل گران‌تر تغییر نمی‌کند.
4. از **Actions → Refresh market and deploy Pages → Run workflow** اجرا کنید. گزینه `force_analysis` گزارش Gemini را بدون انتظار شش‌ساعته تازه می‌کند و ممکن است هزینه داشته باشد.
5. پس از موفقیت job انتشار، آدرس سایت: **https://mostafa5804.github.io/iran-gold-radar/**

**ریپوی Private روی GitHub Free امکان Pages ندارد؛ پلن سازگار مانند Pro لازم است. خصوصی‌بودن ریپو به معنی خصوصی‌بودن سایت Pages نیست.** برنامه برای اطلاعات شخصی از مرورگر استفاده می‌کند و کلید، بودجه و معاملات در خروجی سایت قرار نمی‌گیرند. سایت ورود کاربری یا همگام‌سازی بین دستگاه‌ها ندارد.

اگر job انتشار با «Get Pages site failed» متوقف شد، مرحله اول را انجام دهید و job ناموفق را دوباره اجرا کنید. اگر اکشن اجازه نوشتن به مخزن ندارد، Settings → Actions → General → Workflow permissions و سیاست‌های ریپو را بررسی کنید.

## قابلیت‌های عملی

- قیمت واقعی طلای ۱۸ عیار، دلار آزاد و اونس از صفحات عمومی TGJU، همراه با زمان منبع و دریافت؛ ریال فقط یک بار به تومان تبدیل می‌شود.
- جمع‌آوری خودکار ساعتی در Actions؛ زمان‌بندی GitHub تضمین دقیقه‌ای ندارد. دکمه سایت آخرین فایل منتشرشده را می‌گیرد، نه اینکه اکشن جدید راه بیندازد.
- آرشیو روزانه OHLC، نمودار تعاملی ساده با tooltip، RSI و میانگین ۲۰ دوره و ATR ساده ۱۴ دوره.
- اختلاف با ارزش محاسباتی اونس × دلار × ۰٫۷۵ ÷ ۳۱٫۱۰۳۴۷۶۸؛ این اختلاف به‌تنهایی فرصت آربیتراژ یا حباب قابل‌تخلیه نیست.
- نمودار مرجع هفتگی، ماهانه، سه‌ماهه و سالانه با بازه اسمی ۸۰٪؛ آزمایشی و بدون ادعای احتمال کالیبره‌شده.
- سناریوی قابل‌تنظیم دلار، اونس و فاصله داخلی؛ هیچ ضریب ساختگی برای جنگ ندارد.
- گزارش فارسی Gemini با Google Search برای جنگ، مذاکرات، سیاست بانک مرکزی، دلار و اقتصاد جهانی؛ پیشنهاد کیفی مشروط، منابع قابل‌بررسی و تاریخ گزارش. اجرای زمان‌بندی‌شده حداکثر هر شش ساعت با Secret؛ تحلیل درخواستی با کلید تنظیمات مرورگر.
- فهرست واقعی و صفحه‌بندی‌شده مدل‌های Gemini در تنظیمات. خطای سهمیه یا مدل بدون ادعای موفقیت نمایش داده می‌شود.
- سبد شخصی، خرید و فروش، کارمزد، تبدیل وزن آب‌شده به معادل عیار ۷۵۰، نرخ بازخرید فروشنده، برنامه تقسیم نقدینگی به پله‌ها، پشتیبان JSON و بازیابی.

## امنیت کلید و اطلاعات

روش ترجیحی: Secret در Actions؛ کلید فقط در گام تحلیل قرار می‌گیرد. فایل منتشرشده فقط گزارش و منابع را دارد. گزارش تولیدشده توسط AI قبل از انتشار برای انعکاس احتمالی کلید بررسی می‌شود.

روش درخواستی مرورگر: کلید در تنظیمات وارد می‌شود و مستقیماً با هدر `x-goog-api-key` به Google می‌رود. پیش‌فرض فقط در حافظه صفحه است. نگهداری در `sessionStorage` اختیاری است؛ این مخزن رمزنگاری‌شده نیست و اسکریپت‌های همان origin یا افزونه‌های مجاز می‌توانند به آن دسترسی داشته باشند. Pages سایت‌های یک حساب origin مشترک دارد؛ برای حفاظت قوی‌تر از روش Secret یا backend اختصاصی استفاده کنید. هیچ کد شخص ثالث اجرایی از CDN بارگذاری نمی‌شود. فونت وزیرمتن محلی است.

معاملات، بودجه و دفتر تحلیل‌ها در `localStorage` هستند. با پاک‌شدن مرورگر حذف می‌شوند. پشتیبان را در محل امن نگه دارید. مبلغ، سبد یا معاملات شخصی به Gemini ارسال نمی‌شود. لینک منابع تنها HTTPS است و HTML تولیدشده Google برای Search Suggestions در iframe sandbox بدون مجوز اجرای اسکریپت نمایش داده می‌شود.

## روش عددی و محدودیت‌ها

این نسخه **مدل پیش‌بینی چندعاملی آموزش‌دیده نیست**. تحلیل خبری Gemini از مدل مرجع عددی جداست. مدل مرجع میانه ثابت دارد و بازده لگاریتمی با نوسان ثابت را فرض می‌کند. نوسان از حداکثر ۹۰ فاصله تاریخی و مجموع روزهای تقویمی تخمین زده می‌شود. بازه ۸۰٪ صرفاً اسمی است؛ جنگ، جهش ارز و تغییر ساختار بازار می‌تواند آن را بی‌اعتبار کند. احتمال رشد/افت یا «دقت ۹۰٪» نمایش داده نمی‌شود.

بک‌تست رو به جلو تنها به گذشته دسترسی دارد؛ پنجره‌های هم‌پوشان مستقل نیستند. برای نمایش پوشش تجربی و MAPE حداقل ۳۰ مبدأ آزمون لازم است. آغاز کار معمولاً ۳۰ روز آرشیو دارد؛ تاریخچه با اجراهای بعدی انباشته می‌شود. بازده استراتژی پس از هزینه، یا مزیت نسبت به خرید و نگهداری، هنوز اثبات نشده است.

کیفیت داده: داده خراب رد می‌شود؛ در قطع منبع نرخ قبلی با برچسب stale حفظ می‌شود. تازه‌بودن دریافت، تازه‌بودن معامله را تضمین نمی‌کند؛ TGJU گاهی فقط ساعت معامله و زمان صفحه را ارائه می‌کند. اختلاف زمان بازارها در محاسبه فاصله مؤثر است. در قدیمی‌بودن صفحه یا دریافت، محاسبه فاصله و تحلیل معاملاتی جدید مسدود می‌شود. خبرها نیازمند بررسی منابع‌اند؛ دسترسی به تمام اخبار یا داده‌های بانک مرکزی تضمین نمی‌شود.

اتصال TGJU یک آداپتور صفحات عمومی است و API دارای SLA نیست؛ تغییر HTML، محدودیت دسترسی یا شرایط مجوز می‌تواند آن را متوقف کند. برای استفاده تجاری یا انتشار مجدد گسترده، شرایط ارائه‌دهنده را بررسی و در صورت نیاز داده مجوزدار جایگزین کنید.

## توسعه و آزمون

بدون npm dependency یا build tool؛ Python 3.10+ و Node 20+:

```bash
python3 scripts/collect.py
node --test tests/*.test.js
python3 -m unittest discover -s tests -p 'test_*.py'
python3 -m http.server 8000 --directory public
```

جمع‌آوری و تحلیل در Python استاندارد؛ frontend در `public/`؛ فرمول‌ها در `public/engine.js`؛ اکشن در `.github/workflows/pages.yml`.
